«Weather Diary» — простое приложение для ведения дневника погоды. Позволяет добавлять записи с датой, температурой, описанием и осадками, фильтровать их по дате и температуре, а также сохранять и загружать данные из файла JSON.
Как запустить приложение:

    1. Установите Python 3.8+.
    2. Установите необходимые библиотеки:
    
    pip install tkinter json datetime

    3. Запустите скрипт:

    python weather_diary.py

    4. Используйте интерфейс для работы с записями.
    5. Данные сохраняются в файл weather_diary.json.
    6. Для работы с историей изменений используйте Git.
    7. Проект размещён на GitHub: [ссылка на репозиторий].



**Примеры использования**
- Добавьте запись: дата — 2026-04-24, температура — 15.5°C, описание — «солнечно», осадки — нет.
- Отфильтруйте записи за 2026-04-24.
- Отфильтруйте записи с температурой выше +10°C.
- Сохраните данные в JSON и загрузите их снова.
